# AWS Research

## Brief Overview
Amazon Web Services (AWS) is a cloud computing platform created by Amazon. It was launched in 2006 and is known as one of the first and largest cloud providers in the world. It offers a wide range of services for computing, storage, databases, networking, and more.

## Global Infrastructure
AWS operates in many regions around the world, with each region containing multiple availability zones. This setup allows businesses to run their applications close to their customers and stay online even if one location has a problem.

## Cloud Management Console
AWS provides a web-based tool called the AWS Management Console. It lets users create, monitor, and manage cloud resources through a simple interface without needing to use only command-line tools.

## Four Core Services
1. **EC2 (Elastic Compute Cloud)** – Provides virtual servers for running applications.
2. **S3 (Simple Storage Service)** – Used for storing and retrieving files and data.
3. **RDS (Relational Database Service)** – A managed database service for SQL databases.
4. **IAM (Identity and Access Management)** – Controls who can access AWS resources and what they can do.

## Three Advantages
1. AWS offers the widest range of services compared to other cloud providers.
2. It has a large global network of data centers, which improves speed and reliability.
3. It has strong documentation and a large community, making it easier to find support and solutions.

## Typical Enterprise Use Cases
AWS is commonly used by companies that need to host websites, run mobile app backends, store large amounts of data, and build machine learning applications. Many startups and large enterprises use AWS because it can scale from small projects to very large systems.
