# Client Recommendations

## Client A – Startup Company

**Recommended Platform:** Amazon Web Services (AWS)

**Explanation:** AWS is a good fit for this startup because it offers a free tier and pay-as-you-go pricing, which helps keep costs low in the early stages. It also has services that can scale easily as the app grows, so the startup will not need to switch providers later. AWS also has a large community and many tutorials, which is helpful for a small team with limited resources.

**Services the client could use:**
1. **Amazon EC2** – to host the backend of the mobile application.
2. **Amazon RDS** – to manage the app's database.
3. **AWS Amplify** – to help build and deploy the mobile app quickly.

## Client B – University

**Recommended Platform:** Microsoft Azure

**Explanation:** Azure is the best choice for this university because it is made by Microsoft and connects easily with the tools they already use, like Active Directory and Microsoft 365. This makes the migration simpler, since the university will not need to replace their existing systems. Azure also offers strong support for hybrid cloud setups, allowing the university to keep some systems on their own servers while moving others to the cloud.

**Services the client could use:**
1. **Azure Virtual Machines** – to host university applications in the cloud.
2. **Microsoft Entra ID** – to manage student and staff accounts using their existing Active Directory setup.
3. **Azure Blob Storage** – to store files, documents, and backups.

## Client C – AI Research Company

**Recommended Platform:** Google Cloud Platform (GCP)

**Explanation:** GCP is the best choice for this research company because Google created many of the tools widely used in AI and machine learning today. GCP offers strong support for high-performance computing, which is needed to train complex AI models. It is also well known for Kubernetes, which is useful for managing large-scale computing workloads.

**Services the client could use:**
1. **Compute Engine** – to run high-performance computing tasks.
2. **Google Kubernetes Engine (GKE)** – to manage containerized AI workloads.
3. **Vertex AI** – to build, train, and deploy machine learning models.

---

## Client D – Global E-Commerce Company

**Recommended Platform:** Amazon Web Services (AWS)

**Explanation:** AWS is the best fit for this global e-commerce company because it has data centers in many regions around the world, which helps keep the website fast for customers everywhere. AWS also offers strong auto-scaling features, so the platform can handle sudden increases in traffic, such as during sales events. Its wide range of services also supports the many different needs of a large online store.

**Services the client could use:**
1. **Amazon EC2 with Auto Scaling** – to automatically adjust server capacity based on traffic.
2. **Amazon S3** – to store product images and files.
3. **Amazon CloudFront** – to deliver content quickly to customers around the world.
