## Guide Questions

**1. Which cloud provider offers the broadest range of services?**

AWS offers the broadest range of services. It was the first major cloud provider and has had the most time to build a large number of tools for computing, storage, databases, AI, and more.

**2. Which provider best integrates with Microsoft technologies?**

Microsoft Azure best integrates with Microsoft technologies. Since Azure is also made by Microsoft, it connects easily with tools like Windows Server, Office 365, and Active Directory.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**

Google Cloud Platform is the strongest in Artificial Intelligence and Kubernetes. Google created many of the tools used in AI research, and it also originally built Kubernetes before making it open source.

**4. Which cloud platform would you personally choose and why?**

I would personally choose AWS because it offers the widest variety of services and has strong documentation and community support. This makes it easier to find solutions and learn new tools while working on different types of projects.
