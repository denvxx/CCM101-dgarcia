# Google Cloud Platform

## Brief Overview
Google Cloud Platform (GCP) is a cloud computing platform created by Google. It was launched in 2008 and is known for its strength in data analytics, artificial intelligence, and machine learning.

## Global Infrastructure
GCP has data centers organized into regions and zones around the world. Google is known for its fast and reliable global network, which connects its data centers efficiently.

## Cloud Management Console
GCP provides the Google Cloud Console, a web-based interface for creating and managing cloud resources. It is designed to be simple and easy to use, especially for developers.

## Four Core Services
1. **Compute Engine** – Provides virtual machines for running applications, similar to AWS EC2 and Azure Virtual Machines.
2. **Cloud Storage** – Used for storing and retrieving files and data.
3. **Cloud SQL** – A managed database service for SQL databases.
4. **Cloud IAM** – Controls who can access GCP resources and what actions they can perform.

## Three Advantages
1. GCP is well known for its strength in artificial intelligence and machine learning tools.
2. It offers Kubernetes as a native service, since Google originally created Kubernetes.
3. It has a strong reputation for fast and reliable networking infrastructure.

## Typical Enterprise Use Cases
GCP is commonly used by companies that focus on data analytics, AI, and machine learning applications. It is also a popular choice for companies that use Kubernetes and containerized applications.
