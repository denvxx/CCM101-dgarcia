# Microsoft Azure

## Brief Overview
Microsoft Azure is a cloud computing platform created by Microsoft. It was launched in 2010 and is widely used by companies that already rely on Microsoft products like Windows Server and Office 365.

## Global Infrastructure
Azure has data centers in many regions across the world, organized into regions and availability zones, similar to AWS. This helps businesses keep their applications fast and reliable for users in different countries.

## Cloud Management Console
Azure provides the Azure Portal, a web-based dashboard where users can create and manage cloud resources. It also connects smoothly with other Microsoft tools like Active Directory.

## Four Core Services
1. **Virtual Machines** – Provides virtual servers for running applications, similar to AWS EC2.
2. **Blob Storage** – Used for storing large amounts of unstructured data like files and images.
3. **Azure SQL Database** – A managed database service for SQL databases.
4. **Microsoft Entra ID (formerly Azure AD)** – Manages user identity and access across Microsoft services.

## Three Advantages
1. Azure works very well with Microsoft products like Windows Server, Office 365, and Active Directory.
2. It offers strong hybrid cloud support, allowing businesses to connect their own servers with the cloud.
3. It has a large number of enterprise-focused tools, making it a good fit for large organizations.

## Typical Enterprise Use Cases
Azure is commonly used by companies that already use Microsoft software, such as universities, banks, and large corporations. It is often chosen by organizations that need to connect their existing on-premises systems with the cloud.
