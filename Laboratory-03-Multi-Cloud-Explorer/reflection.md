# Reflection

Among the three cloud platforms, Amazon Web Services impressed me the most. It offers the widest range of services and has a long history as one of the first major cloud providers. Its large community and strong documentation make it easier to learn and find solutions, which is valuable for someone who is still building cloud computing skills.

Despite their differences, AWS, Azure, and GCP share several similarities. All three offer virtual machines for computing, object storage for saving files, identity and access management for controlling user permissions, and managed database services. They also all operate through global networks of data centers, allowing businesses to run applications close to their customers around the world.

Business requirements play a major role in choosing a cloud platform. A company that already uses Microsoft products would benefit more from Azure because of its smooth integration with tools like Active Directory. A company focused on artificial intelligence would benefit more from GCP because of its strong machine learning tools. This shows that there is no single best cloud provider, only the one that fits a specific business need.

Acting as a Cloud Solutions Consultant taught me that technical decisions should always be guided by the client's actual problem, not just by which platform is most popular. I learned how to research official documentation, compare services across providers, and match business needs to the right technical solution. This experience also improved my ability to explain technical topics in a clear and simple way, which is an important skill for working with clients.

My GitHub Cloud Computing Portfolio has improved because it now shows that I can do more than just use basic Linux commands. It demonstrates that I can research multiple cloud platforms, compare their services, and create practical recommendations for real business scenarios, similar to the kind of work a cloud solutions architect would produce.
