# Laboratory 1 - Welcome to the Cloud

## Mission Overview
As a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies, I completed the onboarding mission for cloud engineers. This involved setting up a Linux environment using KillerCoda, exploring the system, organizing files and directories, and building a professional GitHub portfolio to document my work using Markdown.

## Objectives
- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.
- Demonstrate proper documentation practices used by cloud professionals.

## Activities Performed
1. Launched an Ubuntu 24.04 Linux Playground on KillerCoda.
2. Created a new user account (`dgarcia`) with a home directory and sudo privileges, then logged into it.
3. Recorded the current username, working directory, and hostname.
4. Investigated the Linux environment, including the distribution, kernel version, CPU information, memory, and disk space, and documented the findings in `system-information.md`.
5. Created a folder structure (Documents, Notes, Reports, Screenshots) inside the home directory.
6. Created an `about-me.md` file inside the Notes folder.
7. Created a public GitHub repository (`CCM101-dgarcia`) to serve as my Cloud Computing Portfolio.
8. Organized the repository with a root README, a laboratory folder, and supporting files.
9. Documented this mission in a dedicated README file.
10. Captured and organized screenshots as evidence of each checkpoint.

## Linux Commands Used
| Command | Purpose |
|---|---|
| `sudo adduser dgarcia` | Create a new user account |
| `sudo usermod -aG sudo dgarcia` | Grant sudo privileges to the new user |
| `su - dgarcia` | Switch to the new user account |
| `whoami` | Display current username |
| `pwd` | Display current working directory |
| `hostname` | Display system hostname |
| `lsb_release -a` | Show Linux distribution details |
| `uname -r` | Show kernel version |
| `lscpu` | Show CPU information |
| `free -h` | Show memory usage |
| `df -h` | Show disk space usage |
| `mkdir` | Create directories |
| `cd` | Change directory |
| `nano` | Create/edit files |
| `cat` | View file contents |
| `ls` | List directory contents |

## Skills Learned
- Navigating and exploring a Linux environment using the command line.
- Creating and managing user accounts and permissions with `sudo` and `adduser`.
- Gathering and interpreting system information (OS, kernel, CPU, memory, disk).
- Organizing files and directories using basic Linux commands.
- Writing and formatting technical documentation using Markdown.
- Setting up and structuring a professional GitHub repository as a portfolio.
- Following professional documentation and version control practices used by cloud engineers.
