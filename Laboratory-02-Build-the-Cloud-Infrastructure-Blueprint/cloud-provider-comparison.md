# Cloud Provider Comparison

## Comparison Table

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | EC2 (Elastic Compute Cloud) | Virtual Machines | Compute Engine |
| Storage | S3 (Simple Storage Service) | Blob Storage | Cloud Storage |
| Networking | VPC (Virtual Private Cloud) | Virtual Network | VPC (Virtual Private Cloud) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID (Azure AD) | Cloud IAM |

## Guide Questions

**1. Which cloud provider offers the broadest range of services? Explain your answer.**
AWS offers the broadest range of services. It was the first major cloud provider and has had more time to build many different tools for computing, storage, databases, AI, and more.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?**
Microsoft Azure would be the best choice for a company that already uses Microsoft products like Windows Server, Office 365, or Active Directory. Azure connects easily with these tools, making it simpler to manage everything in one place.

**3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?**
Google Cloud Platform is well known for AI and Machine Learning because Google created many of the tools used in this field. GCP is also known for Kubernetes, since Google originally built Kubernetes before making it open source.

**4. What similarities did you observe among the three cloud providers?**
All three providers offer the same basic building blocks: compute (virtual machines), storage (for saving files and data), networking (to connect resources), and identity management (to control who can access what). They just use different names for similar services.
